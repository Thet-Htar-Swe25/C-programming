## File Organization

Each folder is organized according to the C programming topic it represents.

Use this general pattern:

- `.c` files contain C source code
- `.exe` files are compiled executable programs
- Source files are generally named after the topic or exercise
- Standalone programs are usually placed in the folder matching their main topic
- Mixed or later practice programs are stored inside `main/`
- Homework and assignments are stored inside `assignments/`
- Function-specific exercises are stored inside `function/`
- Loop-specific exercises are stored inside `loop/`
- Sorting programs are stored inside `sorting/`
- Operator exercises are stored inside `operators/`

## How to Compile a Program

Open a terminal inside the folder that contains the C file, then use:

```bash
gcc filename.c -o filename
```

For example:

```bash
gcc hello.c -o hello
```

On Linux or macOS, run:

```bash
./hello
```

On Windows, run:

```bash
hello.exe
```

## Development Rules I Follow

- Write one C program at a time
- Compile programs before running them
- Read compiler errors and warnings carefully
- Test programs with normal and invalid input
- Use meaningful variable and function names
- Keep source code in the appropriate folder
- Compare different versions of a solution
- Practice both iterative and recursive approaches
- Check array boundaries before accessing elements
- Clear or manage the input buffer when mixing character and numeric input
- Use `#include <stdio.h>` for standard input and output
- Use `#include <stdlib.h>` when dynamic memory or process-control functions are needed
- Use `#include <string.h>` when using string functions
- Improve older exercises instead of only creating copies
